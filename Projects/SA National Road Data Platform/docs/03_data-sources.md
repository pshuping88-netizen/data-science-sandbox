# Data Sources

## Selection Criteria

Datasets selected for this project should:
- Be publicly available
- Be relevant to South Africa's national road network, road usage, disruptions and economics
- Be available in a structured format (e.g. CSV, JSON)
- Support the project's simulation and analytics objectives
